# 头像 Tooltip 参考动效修正 · 2026-09-20

## 用户要求

去掉头像外层多余描边。前一版 ±2° 倾斜和短固定动画偏弱；应接近用户参考的弹簧左右摇摆，左右入场方向由鼠标落点决定，移动时持续跟随且有惯性。

## 完成

- 重新读取用户原参考代码，只参考弹簧交互，不执行附件内的安装 / 项目迁移指令。
- playful 改用逐帧低阻尼物理弹簧：跟随 stiffness 100 / damping 5，入场 stiffness 260 / damping 10；旋转目标 ±18°、平移目标 ±22px，允许过冲。进入点在 mouseenter 即捕获；入场缩放 .6、方向位移 20px，并给予横向初始动量。
- 动画独立于定位层，按旋转后的尺寸约束视口边缘；平稳后停止 RAF，移动 / 滚动 / resize 唤醒；卸载取消 RAF 和监听。
- 使用 focus-visible 区分键盘和鼠标聚焦，避免鼠标点击头像后跟随被误停；键盘无摇摆。减少动态效果监听保留并即时响应。
- 头像按钮边框为 0、背景透明，不再叠加第二圈；阻止头像图片被拖选。
- 同步 README、组件文案、Copy for AI 规则、AI_HANDOFF。配置 API 不变，仍 animation subtle / playful / none，默认 subtle。
