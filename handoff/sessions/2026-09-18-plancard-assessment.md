## 设计依据与发现
- Figma 文件 LLvI9vd66VLNuAltAWJFJw，节点 51:213896；已读取 get_design_context 和随附截图。
- 一个白色 24px 圆角外壳，浅描边，内部两列两行分隔，四区为 Analysis / Growth plan / Engage / Publish。
- 通用结构：图标 + 标题 + 分类与积分标签 + 说明；功能勾选清单；Engage 数值信息条与 Publish 图标能力条；底部平台图标与 +N 汇总。
- 该节点没有价格、计费周期、购买按钮；现有 PlanCard.tsx 强依赖这些套餐字段，直接替换会混淆业务语义。

## 建议（尚未确认）
- 扩展 Card / CardGrid：无间隙、内部单线分隔的连体分区；外壳统一圆角，子区不再套完整描边卡片，列数与内容不绑定四区。
- 新增 FeatureList：只读图标 / 勾选 + 富文本 + 可选补充内容；不是 Checkbox。
- 评估扩展 StatCardGroup / StatCard 为紧凑信息条，容纳数值或图标、标签及 Tooltip；不新增重复的数据卡。
- 标题区域先复用 Card 标题插槽、Badge、Tooltip，作为组合内部结构；不急于独立新增标题组件。
- 平台图标组可作为第二阶段小组件，支持并排 / 叠放、显示上限和 +N；继续复用已有图标资源。
- 新版整体适合称 FeatureOverview（功能 / 权益总览）组合，套餐页消费它；旧 PlanCard 保留，替换范围待用户决定。
- 响应式按内容变成单列，重排分隔线，不写死设计稿行高。静态能力展示不默认添加可点击 / 选中态。
