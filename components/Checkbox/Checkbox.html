Checkbox

Select one or more independent options. The whole row can provide the module-color hover preview before selection.

Overview / Example

States

Default
Row hover
Selected
Disabled

Usage

Use checkboxes for independent choices. Use a Toggle for an immediate on/off setting and a Select for one value from a menu.

Specs

18×18px · radius 4px · 1.5px black border · selected/row-hover fill uses the active module color.
