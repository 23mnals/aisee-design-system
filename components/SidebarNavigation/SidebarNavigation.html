Interaction NEW

  • Overview is a leaf destination; every other primary item can expand independently.
  • Expanded mode shows nested destinations inline with a guide rail.
  • The toggle uses the platform-native w-resize cursor while closing, and the collapsed rail uses e-resize while opening; no custom cursor asset is used.
  • Collapsed mode applies the native open-direction cursor across the rail; clicking blank rail space opens the sidebar while feature icons continue to open child flyouts.
  • Hover and selected rows use 4% black; the content region stays visible in both sidebar widths.
