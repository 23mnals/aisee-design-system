Toggle

A binary control with fluid hover, press and spring-like state feedback.

Apply the AISEE design or add motion to your existing component. Integration guide

Overview / Examples NEW

Colors / Surfaces / Sizes NEW

Motion NEW

Hover stretches the thumb, press compresses it, and a spring-like 250ms transition carries it between states. Reduced-motion preferences are respected.

States NEW

On and off states; focus keeps a visible outline and disabled state suppresses hover and press feedback.

Specs NEW

16px: track 24×16px, thumb 10×10px, 1px dark border. 24px: track 43.64×24px, thumb 17.45×17.45px, 1.31px dark border. Size refers to track height.

  • Lime #CFFF29 / yellow #FFE253 with #111 outlines and thumbs.
  • Dark surfaces preserve both active fills and the dark outline / thumb. Inactive tracks use translucent white; labels and keyboard focus adapt to the dark background.
  • Keep the existing 16px control and module color when no variant is supplied.

<Toggle color="yellow" surface="dark" size={24} label="Automation" defaultChecked />
