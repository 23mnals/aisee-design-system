Usage NEW

Inside the AISEE repository / package

Import the exported React component and the shared stylesheet. This is the preferred integration because updates stay centralized.

import { QuantityStepper } from '@aisee/design-system';
import '@aisee/design-system/styles.css';

<QuantityStepper
  defaultValue={4}
  min={1}
  max={10}
  unit="replies/day"
  onValueChange={setQuantity}
/>

Without the AISEE Design System

Use Open HTML for a self-contained reference, or vendor the component source, its Quantity Stepper CSS block and the two approved StemUI icons. Do not replace them with text glyphs.

npm install @stemui/icons@0.1.40

Required icon sources:
line_line_nochange.svg
line_plus_add.svg
  • Props: value / defaultValue, min, max, step, size, inputMode, unit, disabled, onValueChange and ariaLabel.
  • Use inputMode="editable" when exact entry matters; use buttons-only for a short bounded range.
  • The 40px component follows the Figma 388px composition, including controls that touch the outer outline, 3px section gaps and StemUI minus / plus icons.
  • Below 260px available width, the unit is hidden automatically and the numeric value remains visible.
  • Number changes roll vertically. Pressing a control squishes it to 85%; holding for 400ms repeats at 80ms, then accelerates to 40ms.
  • A blocked step keeps the value unchanged and shakes only the value area by at most 4px for 300ms.
