Usage

Figma source: Figma node 77:17878. Motion triggers: a new notification rings the inner white bell and rolls the unread badge; hover or keyboard focus rings only the white bell. The 32px button and black circular icon base remain fixed. In an application, update the bell count when incoming notifications arrive through a push subscription or polling; an increase automatically triggers the motion. The simulation button is only a demo control. Reset demo restores four unread notifications and replays the bell and badge animation, even if the count was already four. Marking notifications as read does not trigger the incoming animation. Color: default surface uses colour/bg/hover, hover uses colour/bg/yellow-mid, and unread indicators use colour/feedback/wrong. Clicking an item marks it read; tabs filter the list; “Mark all as read” clears every marker. Reduced motion removes decorative animation.
