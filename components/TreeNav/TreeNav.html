Tree Nav

A focused local navigation list with a hierarchy rail, leaf selection and disabled states. Sidebar Navigation uses this component in its expanded state.

Interactive preview NEW

Interaction

  • The standalone preview starts directly with leaf options; the surrounding page supplies any section title.
  • Keep each Tree Nav instance focused on one local list instead of reproducing the complete product sidebar.
  • The rail communicates hierarchy; the selected leaf uses the same subtle surface as hover.
  • Disabled items remain visible but cannot be selected.

Usage

Use Tree Nav for a focused local list of related destinations. Add a parent disclosure only when the surrounding context does not already provide the group title. Use Sidebar Navigation for the complete application rail, multiple product groups, collapse behavior, account footer and collapsed flyouts.
