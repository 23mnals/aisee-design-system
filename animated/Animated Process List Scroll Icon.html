Animated process-list icon — scroll

Hover any icon — a row completes (its check ticks on, its line strikes across), then the whole list slides up one row, the finished row fades out the top, and a fresh blank row arrives at the bottom to complete next. Endless self-clearing checklist.

How it works
one belt, stepped + masked
/* 7 identical rows stacked on a belt, clipped to the 16×16 box. */ /* A fixed fade mask dissolves rows at the top & bottom edges. */ @keyframes plc-belt { 0%, 22% { transform: translateY(0); } /* row completes at the active slot */ 31%, 56% { transform: translateY(-4.421px); } /* slide up one row, next completes */ 65%, 90% { transform: translateY(-8.842px); } 99%, 100% { transform: translateY(-13.264px);} /* after 3 rows the loop reseats seamlessly */ } /* each incoming row strikes its LINE first, then ticks its check */
