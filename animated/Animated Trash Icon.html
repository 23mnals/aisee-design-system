Animated delete / trash icon

Hover any icon — the lid flips open around its right end, a small speck flies up-right and fades, then the lid snaps shut. Body, walls and the three inner lines stay still.

How it works
three groups, one keyframes
/* CSS */ .trash svg .trash-body { transform-box: view-box; transform-origin: 12px 7px; } .trash svg .trash-lid { transform-box: view-box; transform-origin: 21px 7px; } .trash svg .trash-speck { transform-box: view-box; transform-origin: 10px 11px; opacity: 0; } .trash:hover svg .trash-lid { animation: trash-lid-flip 1.3s ease-in-out infinite; } .trash:hover svg .trash-body { animation: trash-body-stretch 1.3s ease-in-out infinite; } .trash:hover svg .trash-speck { animation: trash-speck-fly 1.3s ease-in infinite; } @keyframes trash-lid-flip { 0% { transform: rotate(0); } /* rest */ 15% { transform: rotate(0); } /* hold */ 40% { transform: rotate(28deg);} /* opens up-left */ 55% { transform: rotate(28deg);} 75% { transform: rotate(0); } /* snap shut */ 100% { transform: rotate(0); } } @keyframes trash-body-stretch { 0%,15% { transform: scaleY(1); } /* rest */ 40% { transform: scaleY(1.10); } /* stretched DOWN */ 55% { transform: scaleY(1.10); } 72% { transform: scaleY(.95); } /* overshoot up */ 85% { transform: scaleY(1.03); } /* bounce */ 94% { transform: scaleY(.99); } 100% { transform: scaleY(1); } } @keyframes trash-speck-fly { 0%,18% { opacity:0; transform: translate(0,-9px) scaleY(.25); } /* parked OUTSIDE above lid */ 25% { opacity:1; transform: translate(0,-8px) scaleY(.25); } /* appears OUTSIDE above lid */ 42% { opacity:1; transform: translate(0,-6px) scaleY(.35); } /* approaching opening */ 55% { opacity:1; transform: translate(0,-3px) scaleY(.6); } /* descending INSIDE */ 66% { opacity:1; transform: translate(0,0) scaleY(1); } /* merged with left line */ 78% { opacity:0; transform: translate(0,0) scaleY(1); } 100% { opacity:0; transform: translate(0,-9px) scaleY(.25); } }
