Animated process-list icon

Hover any icon — the list completes one row at a time: a check ticks on, its line strikes across left → right, then the next row, then the next. Once all three are done the list clears and starts over.

How it works
six paths, one timeline
/* Split the icon into 3 checks + 3 lines. pathLength="100" normalises the dash math. */ .pl svg .pl-line { stroke-dasharray: 100; } .pl svg .pl-check { transform-box: fill-box; transform-origin: center; } /* One 2.7s timeline. Each row owns a window: check ON, then line strikes across. */ @keyframes pl-check-1 { 2% { opacity: 0; transform: scale(.4); } 7% { opacity: 1; transform: scale(1.25); } /* tick on */ 12% { opacity: 1; transform: scale(1); } /* …holds done */ } @keyframes pl-line-1 { 9% { stroke-dashoffset: 100; } /* wait for the check */ 26% { stroke-dashoffset: 0; } /* strike across L→R */ } /* row 2 runs ~35–59%, row 3 ~68–92%, then check-3 + line-3 clear at 100% */ /* so the whole list resets and the loop repeats. */
