Recommendation: ship A (resting pill) as default, with B on hover and C on click. The pill earns its space because it doubles as a system-health indicator (shows red/yellow if disconnected, out of date, etc).
Use the lime/olive family for "good / connected" states — visually distinct from the brand yellow used for active CTAs, so users learn: yellow = action needed, green = all set.
03 — situational re-entry

Inline contextual trigger

If the user dismissed the onboarding card, surface the install offer at the exact moment they'd benefit from it — when they try to reply, post, or open a signal. Highest conversion because the motivation is concrete.

Feature-gated CTA: the button is visible but locked. The tooltip explains why and offers install in one click. Best for power features.
My pick: A for the Reply flow (Reply is the #1 reason users want the extension). B works well for secondary plugin-only features like "auto-detect new signals" or "1-click upvote".
Frequency cap: after the user dismisses the banner once on a card, don't show it again for that session. Show again next day (or after 5 reply actions, whichever first). Avoid feeling naggy.
Combine with section 02: the resting "Extension connected" pill in the top-right is always the canonical entry point. Inline triggers are opportunistic — they boost discovery, not replace the navbar entry.
