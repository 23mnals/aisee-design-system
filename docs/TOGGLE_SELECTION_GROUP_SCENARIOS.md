# Toggle Selection Group：场景与行为验收

设计来源：Figma `tv7gTsQn6OipGVwHG8z0mX / 9704:256746`。示例里的模型名称沿用设计稿，仅作静态演示。

## 核心规则

- 首次开启默认选中全部可用选项。单项不可用时，不因全选而被强行选中。
- 手动取消后，关闭总开关只禁用选项，不清空选择；重新开启恢复上次选择。
- 用户取消全部后再关闭、开启，仍为空选；不能把空数组误判为“第一次使用”。
- `All` 在部分选择时显示中间态，点击补齐所有可用选项；全选时点击则清空可用选项。
- `selectedIds` 是保存的配置，`activeSelectedIds` 是当前实际生效范围；关闭时后者为空。
- 当前页内自动保留；跨页面、刷新或再次登录后的恢复，由业务将 `enabled` 与 `selectedIds` 一起保存后通过受控 `value` 传回。

## 典型场景

| 场景 | 总开关控制 | 下方选项 | 如何使用 |
|---|---|---|---|
| AI 模型分析 | 是否纳入某个平台 | 该平台下的多个模型 | 首开全选，再按成本、速度或能力取消模型；暂时排除平台时保留模型组合；分析请求只取 activeSelectedIds。 |
| 内容采集来源 | 是否启用某一来源组 | X、Reddit、YouTube 等 | 暂停整组采集，不重置来源偏好；恢复后继续按原来源集合采集。 |
| 品牌监测 | 是否启用一类监测 | 品牌提及、竞品、引用等事件 | 可临时暂停监测；重新开启恢复事件类型，而不是再次订阅全部类型。 |
| 报告模块 | 是否包含一个报告区块 | 可见度、情绪、排名等章节 | 关闭整块但保留章节选择；生成报告时跳过关闭区块。 |
| 通知偏好 | 是否启用某一通知渠道 | 报告就绪、任务失败、周报等类别 | 邮件静音后仍记住原类别；重新开启恢复；组件只更新配置，不发送通知。 |
| 发布渠道 | 是否使用某组发布目标 | 账号、主页、社群等 | 临时排除一组目标，不删除账号选择；发布由业务提交动作执行，开关与勾选本身不发布。 |
| 数据导出 | 是否导出某个字段组 | 展示、互动、点击等字段 | 保存定制导出结构；暂停一个字段组后，恢复时不必重新逐项勾选。 |
| 时间安排 | 是否启用一组可用时间 | 上午、下午、晚上等时段 | 暂停计划并保留原时间窗口；具体时区、日期与排程仍由业务处理。 |

## 边界与组合

| 情况 | 当前处理 |
|---|---|
| 新配置、初始关闭 | 不预先勾选；第一次开启选中全部可用项。 |
| 初始开启、没有传历史选择 | 默认选中全部可用项。 |
| 回填部分历史选择 | 传 `{ enabled, selectedIds: [...] }`，严格按历史恢复。 |
| 回填历史空选 | 显式传 `selectedIds: []`，开启后仍为空选。 |
| 总开关关闭 | 单项与 All 均禁用，键盘也不能改动；保留已选外观并降低对比。 |
| 单项不可用 | 显示并禁用该项；All 不改变它；说明原因可用 disabledReason。 |
| 仅查看权限 | 用 disabled 禁用总开关与所有选项，显示原配置。 |
| 可选项列表为空 | 禁用总开关，显示业务提供的 emptyText。 |
| 选项动态新增 | 已保存选择不自动扩张，新项默认不选。 |
| 选项暂时移除 | 保存的 ID 保留，但不计入界面数量和生效范围；恢复同 ID 后可恢复原选择。 |
| 单选项或不需要全选按钮 | 可设置 showAll=false，保留总开关与单项。 |
| 多组同时出现 | 每组独立保存 value，不能共用一个 selectedIds 数组。 |
| 长文本、窄屏、多个 metadata | 标签、选项和头部自然换行；Toggle 保持固定尺寸，按钮左右留白一致。 |
| 开启但零选 | 组件允许；如业务要求至少一项，应在业务提交处校验并说明，不自动帮用户重新全选。 |
| 刷新或组件卸载 | 非受控本地状态不跨卸载保存；需要恢复时使用受控 value 与业务存储。 |

## API 示例

```tsx
const [value, setValue] = useState<ToggleSelectionValue>({ enabled: false });

<ToggleSelectionGroup
  label="google"
  options={models}
  value={value}
  onChange={setValue}
/>

const { activeSelectedIds } = resolveToggleSelection(models, value);
// 业务执行只使用 activeSelectedIds；保存配置仍保存 value。
```

## 不适合直接使用的情况

互斥单选应使用 Radio / Dropdown；立即执行的一次性动作应使用 Button；无“暂停并保留配置”含义的普通筛选只需 Checkbox Group。此组件处理启停与多选配置，不承担请求执行、权限判断或持久化。
