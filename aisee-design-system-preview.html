Product overview

AISEE is an AI visibility and social engagement platform. Six connected capabilities form a continuous diagnose → grow → execute → verify loop, supported by reusable channel and account connections.

01

Analysis / GEO

Measures AI visibility, citation performance, rankings and prompt coverage across generative search platforms.

02

Growth

Turns diagnostic gaps into prioritized improvement plans, key steps and measurable score-growth tasks.

03

Engage

Finds relevant conversations, manages keywords and accounts, drafts replies and tracks response outcomes.

04

Post Agent

Plans, generates, schedules and publishes social content through connected channels and calendar workflows.

05

Verify

Re-scans live visibility after execution, records score changes and verifies whether planned actions created measurable gains.

06

Connection

Manages the channels, social accounts and extension connections required by Growth, Engage and Post workflows.

Capability relationship: Analysis diagnoses → Growth prioritizes → Engage and Post execute → Verify measures the result. Connection supplies the reusable account and channel layer across the loop.

Content fundamentals

AISEE copy should feel precise and helpful: technical enough to be trustworthy, but never dense or theatrical.

Minimal and confident

Use direct language, clear nouns and active verbs. Remove filler and unsupported claims.

Product first, user second

Prefer “Create analysis”, “Your report” and “Connect channel” over abstract system language.

Lowercase brand name

Write “aisee” in product copy. Use “AISEE” only where an all-caps system label is intentionally styled.

No emoji in UI

Use text labels and SVG icons. Keep labels short, recognizable and sentence case.

Numbers stay readable

Show data without decorative formatting; pair unfamiliar metrics with labels or tooltips.

Errors explain the fix

State what happened and the next action. Avoid blame, jokes or generic “Something went wrong”.

Examples

  • CTA: “Start Free”, “New analysis”, “Save changes”
  • Navigation: “Analysis”, “Growth”, “Engage”, “Post”, “Verify”, “Connection”
  • Placeholder: “Enter the website URL” or “Start writing your post…”
  • Error: “Your post needs at least one character or one image.”

Layout, spacing and surfaces

Application shell

70px fixed header, 224px sidebar and 24–32px main content padding.

Spacing

4, 8, 12, 16, 24, 32, 48 and 64px scale. Prefer adjacent steps.

Radius

8px controls, 12px cards, 16px large surfaces and dialogs, 9999px pills.

Borders

Static UI uses 5% black; hover rises to 18%. Modal footer uses the documented 6% exception.

Shadows

Cards remain subtle. Dropdown and modal layers use defined elevation tokens.

Backgrounds

Page #FAFAFA, cards #FFFFFF, warm supporting surfaces only where specified.

Interaction and feedback

Motion clarifies hierarchy and state change. It should never distract from data or delay a primary task.

Hover and active

Use subtle fill or border changes. Module navigation uses its theme accent for active context.

Focus

All keyboard targets require visible focus. Interactive targets remain at least 44×44px.

Motion

120–300ms transitions with the shared easing curve. Respect reduced-motion preferences.

Loading

Preserve layout with skeletons or stable placeholders; disable repeated submissions.

Empty states

Explain what is missing, why it matters and the single next action.

Toast and tooltip

Black surface, white text, short duration and no critical information hidden only on hover.

Imagery, logo and iconography

Product UI stays data-led and clean. Brand pages can use geometric shapes, texture and the cyclops mascot, while product interfaces avoid decorative photography.

Use official logo assets

Never redraw the eye or wordmark with CSS. Preserve proportions and keep a clear safety area. The mark can stand alone; the wordmark should use the supplied artwork.

Icon rules

  • Single source of truth: the StemUI GitHub repository. SVG sources and generated React components are maintained there.
  • Product projects install @stemui/icons from npm; the npm README is the team entry for installation, exports and published-version guidance. The design-system repository does not duplicate the full SVG library.
  • Use 16×16px in standard controls, 20×20px inside buttons and 24×24px for larger navigation or actions.
  • AISEE icons use the line_ outline family or fill_/flat_ solid family. Lucide is a fallback only when StemUI has no matching icon.
  • No icon fonts and no emoji UI icons; use SVG or typed React icon components.
  • Social platform marks keep their official form and brand color at small badge sizes.
