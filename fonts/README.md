# AISEE Fonts

| Font | Scope | Status |
|---|---|---|
| Karla Variable | Homepage, Brand, dApp, App, Webapp | Only live UI font |
| Gotu Regular | Historical asset only | Not used by the live Design System |
| Digital Numbers Regular | Archived / exceptional numeric artwork only | Never use as dApp/App/Webapp global typography |

Rules:

- All Design System pages, including Homepage / Brand previews, use **Karla only** (confirmed 2026-09-11).
- dApp / App / Webapp uses **Karla only**, including headings, data, code hints and score gauges.
- Digital Numbers is retained as an approved resource file, but it does not override the Karla-only application rule.
